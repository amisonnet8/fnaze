# fnaze をこのリポジトリで本式に使う：.fnaze/ をコミットし、使い方のルールと pre-commit を入れた
.gitignore	!/.fnaze/ と !/.githooks/ を足し、説明のファイルとフックを追跡する
.crube/	crube で説明を付けた（ファイルは直接編集していない）
	ignore	.gitignore に合わせて !/.fnaze/ と !/.githooks/ を足した（手で編集）
	structure.txt	crube set で .fnaze/・.fnaze/changes/・*.txt・.githooks/・pre-commit・fnaze-usage.md の英語の説明を付けた
	structure_ja.txt	同じものの日本語の説明を付けた
.fnaze/
	changes/	これまで git の対象外で書いてきた説明のファイルを、そのまま入れた
		| 初めのものは手書き、20261109T053633Z からは fnaze のコマンドで書いた（q 3d24764a7d）
.githooks/
	pre-commit	docs/examples/pre-commit をそのまま写した。説明のファイルを足さないコミットと、status --require が報告するコミットを止める
.devcontainer/
	postCreate.sh	git config core.hooksPath .githooks を足し、fnaze をコミットの説明と pre-commit で使うことを書いた
