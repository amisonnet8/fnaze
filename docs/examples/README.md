# Examples

- `changes/`: two groups of description files, each in `en` and `ja`, as they would be in `.fnaze/changes/`. The second group was started with `fnaze new` from the first and then written
- `pre-commit`: an example git pre-commit hook for using fnaze with one description per commit. fnaze does not require it
